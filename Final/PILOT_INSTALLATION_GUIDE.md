**Аудитория:** пилотный клиент (Materia Medica + резервные кандидаты)
**Версия:** 0.1.0-rc2 (beta) и более поздние до v0.1.0 GA
**Контакт поддержки:** ackold@yandex.ru, ответ в течение 24 часов

> **Краткий контекст для пилота**
>
> Aurora Launch — Bayesian forecast workspace для запуска новых брендов с применением proxy transfer methodology. Это beta-релиз: ваш отзыв напрямую влияет на v0.1.0 GA.
>
> На этой стадии установщик ещё не подписан коммерческим сертификатом юрлица — мы его получаем после регистрации ООО (2-3 недели). Поэтому Windows и macOS покажут предупреждение «неизвестный издатель». Это **не вирус** и **не повреждение** — нужно один раз нажать «Запустить всё равно». После выпуска юрлица обновление прилетит автоматически с правильной подписью.

## Перед началом

| Параметр | Требование |
|---|---|
| OS Windows | Windows 10/11 (64-bit) |
| OS macOS | macOS 11 Big Sur и новее (Apple Silicon или Intel) |
| OS Linux | Ubuntu 22.04+ / Debian 12+ / Fedora 38+ |
| ОЗУ | 8 ГБ минимум (16 ГБ рекомендовано для bundle 200 МБ+) |
| Место на диске | 500 МБ для приложения + место для bundles |
| Сеть | Только для активации лицензии и обновлений; работа полностью офлайн |

Файлы установщика мы вышлем по защищённой ссылке вместе с SHA-256 контрольной суммой. **Сначала проверьте контрольную сумму** — это гарантия что файл не подменён в дороге.

### Проверка SHA-256

**Windows PowerShell:**

```powershell
Get-FileHash "C:\путь\Aurora Launch_0.1.0_x64-setup.exe" -Algorithm SHA256
```

**macOS / Linux Terminal:**

```bash
shasum -a 256 ~/Downloads/Aurora\ Launch_0.1.0_aarch64.dmg
```

Полученная hex-строка должна совпасть с присланной нами. Если не совпадает — **не устанавливайте**, обратитесь к нам.

## Установка на Windows

### Шаг 1. Запустить установщик

Двойной клик по `Aurora Launch_0.1.0_x64-setup.exe`.

### Шаг 2. Пройти SmartScreen

Появится синий экран **«Система Microsoft Defender SmartScreen предотвратила запуск неизвестного приложения»**.

1. Нажмите **«Подробнее»** (мелким шрифтом под текстом).
2. Появится кнопка **«Выполнить в любом случае»** — нажмите.
3. Подтвердите запрос UAC «Разрешить этому приложению вносить изменения».

> Это **разово** — после установки SmartScreen больше не вмешается, и при выходе обновлённой версии с настоящей цифровой подписью предупреждение исчезнет полностью.

### Шаг 3. Пройти мастер NSIS

- Принять лицензионное соглашение (proprietary, описано в `06_References/PRICING_TIERS.md`).
- Выбрать каталог установки. По умолчанию `C:\Program Files\Aurora Launch\`.
- Дождаться завершения (≈30 секунд).
- Запустить с галочкой «Открыть Aurora Launch» или вручную через Пуск.

### Шаг 4. Активация лицензии

При первом запуске введите ключ лицензии, который мы выслали по почте. Активация требует разовый сетевой запрос; затем приложение работает офлайн до 7 дней (offline grace), после чего попросит снова выйти онлайн.

## Установка на macOS

### Шаг 1. Распаковать DMG

Двойной клик по `Aurora Launch_0.1.0_aarch64.dmg` (или `_x64.dmg` для Intel-Mac). Откроется окно с иконкой «Aurora Launch.app» — перетащите её в папку Applications.

### Шаг 2. Снять carantine + первый запуск через Finder

macOS автоматически добавит Quarantine-флаг к скачанному файлу. Чтобы Gatekeeper разрешил запуск без Apple Developer ID:

1. Откройте Finder → Applications.
2. **Правый клик** (или Ctrl+click) по «Aurora Launch» → **«Открыть»**.
3. В диалоге «Aurora Launch не может быть открыта, потому что разработчик не подтверждён» нажмите **«Открыть»**.

> Это **разово** — после первого подтверждения двойной клик будет работать как обычно.

**Если появляется ошибка «Файл повреждён»:**

```bash
xattr -d com.apple.quarantine /Applications/Aurora\ Launch.app
```

После этого попробуйте Шаг 2 ещё раз.

### Шаг 3. Активация лицензии

Аналогично Windows — ввести ключ при первом запуске.

## Установка на Linux

### Опция A. AppImage (рекомендовано — portable)

```bash
chmod +x ~/Downloads/aurora-launch_0.1.0_amd64.AppImage
./aurora-launch_0.1.0_amd64.AppImage
```

Если требуется `libwebkit2gtk-4.1-0`:

```bash

```

```bash
sudo apt install ./aurora-launch_0.1.0_amd64.deb
aurora-launch
```

`Cmd + Shift + F` (macOS) / `Ctrl + Shift + F` (Windows / Linux) — откроется форма обратной связи. Скриншот, версия, лог-файл прикрепляются автоматически. Мы получим уведомление в GitHub Issues и ответим в течение 24 часов (24-48h SLA для critical bugs).

Auto-update откатывается через `Settings → Updates → History → Roll back to previous`.

## Что обновится после регистрации юрлица

После завершения регистрации ООО (ориентировочно 2-3 недели):

1. **Windows:** установщик подпишется Authenticode EV сертификатом → SmartScreen больше не покажет предупреждение.
2. **macOS:** приложение получит Developer ID Apple подпись + notarization → Gatekeeper пропустит без диалога.
3. **Авто-обновление:** обновлённая подписанная версия прилетит через `tauri-plugin-updater` одним кликом, переустанавливать вручную не нужно.

## Конфиденциальность

Aurora Launch работает **локально**. Ваши данные не отправляются в облако. Опциональная анонимная телеметрия отключена по умолчанию (`Settings → Privacy → Send anonymous diagnostics`). Подробности в `03_Architecture/DATA_PRIVACY.md`.

Methodology Certificate подписывается криптографически (Ed25519); каждое предсказание содержит отпечаток модели + ссылку на верификатор `verify.auroraai.pro`.
